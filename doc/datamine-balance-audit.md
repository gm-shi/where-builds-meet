# 刷新后的解包数据对比，2026-10-15

> 译注：本文译自上游 2026-10-15 的审计记录，反映的是上游当时的实现状态。文中所述“玉的战斗技能尚未接入”以及“烟柳仅保留两件套属性”在本分支并不适用：本分支的玉预览已实现这些内容，详见 `doc/jade-implementation-audit.md`。

本审计将当前整理后的实现与刷新后的
`local/datamine/` 导出数据进行对比。由于没有保留更早的导出快照，出现分歧只能说明
当前实现存在差异，而不能说明游戏是在何时变更的。按用户指示，国服（CN）回退记录
可作为证据；版本/层元数据仍用于区分相互冲突的记录。

本次工作修改了飞隼、移经易武的重数位置、四时无常 T0 的持续时间、衍九矢的第二轮齐射，以及缺失的十方破阵/粟子游尘第 14 阶系数例外。下文其他条目均为发现，而非已实现的修改或已批准的秒伤基线。

## 缺失支持与新变更数值

这些是刷新后的来源所确认的现有范围缺口。由于没有旧的
导出数据，不能把它们都称为新的平衡调整。

- **沧浪剑诀：** 缺少 T0/T1/T4 控制命中的武学冷却缩减以及 T6 的
  Bone Grinding。受支持的控制列表现在明确包含鸾鹤舞翅。仅将该技能加入列表
  并不能实现沧浪剑诀；必须先编写其核心事件规则。
- **葫芦飞飞、春雷篇、纵地摘星、花上月令：** 目前是被动属性脚手架；
  玉的战斗技能与关联效果的生命周期尚未接入。滞骨原始增益 431307 的生命周期为五秒，
  但目前没有对应的玉目标效果实现可供更新。
- **君臣药、杏花不见、指玄篇注、千丝蛊：** 大部分资源、接收者、复活与
  会心治疗行为仍缺失。杏花不见可以共享浣花最终需要的会心治疗结果支持，
  而不是引入另一个结果机制。
- **燎原星火、长生无相、晚雪间、丹心篆、困兽心经以及其他功能/防御类心法：**
  导出数据中存在主动机制，而运行时各重大多只包含 T2/T5 属性。这些需要按功能
  限定范围的工作，而不是把技能说明中的百分比复制到无关的伤害类别中。
- **易水歌：** T4 以下 80% 的自身叠层概率仍被当前的普通触发器视为必定触发。
  这已记录在翊审计中。共享的两秒施加冷却与十秒伤害/治疗冷却已存在。
- **极乐泣血 T6：** 导出数据称穿透后保留 1–2 层；运行时保留一层。
  该措辞并未给出分布/选择规则。
- **无名心法 / 千山法 / 威猛歌：** 受支持的 PvE 计算路径与未建模的目标模式限制、
  非首领状态以及控制行为并存。在提出整体替换之前，请参阅现有的技能/天赋文档。
- **大卷微身、一醉千秋、飞仙醉言以及樽的大部分战斗：** 许多效果重数与战斗技能映射
  仍待完成；导出的酒意/酩酊行为并不能构成一个完整、当前可运行的循环。
- **急风骤、烟柳、倾觞以及防具四件套被动：** 许多运行时选项只保留两件套属性。
  断岳/撼天/连星/裁云在共享增益与技能数据中有额外行为；不要仅凭其设置选项
  就将其归类为缺失。
- **太白醉月 T5：** 更新后的来源升级 305 明确包含最后一击额外返还的四点精元；
  当前的最后一击组件遗漏了它。先前记录的奇术阶位适用资格问题仍然存在。
- **Blinding Mist、Touch of Death 以及其他缺失的奇术：** 来源中可用并不等于运行时可用。
  它们的消耗、冷却与伤害交互需要实际的技能记录。一旦确定了适用资格与时机，
  通用的伤害/资源机制即可覆盖大部分数值行为。
- **计算得出的真气伤害：** 在共享的真气计算/反馈流水线存在之前，延迟结算与 DOT 的
  真气变化无法移动编写的真气击破。现有的气血重放行为不得被普通的攻击判定取代。
- **100 阶合并的奇术词条：** 来自所提供补丁的这一项仍待完成。运行时保留单体类与
  群体类奇术属性；其迁移/承音工作与当前的飞隼修改相互独立。

## 数值检查与来源冲突

- 全部 60 个心法名称均相符。在拆分导出的最小/最大值对并加上运行时索引为零的位置之后，
  现有直到单人等级 21 的 T2 数值与来源表一致；额外导出的 22/23 级在运行时数组中
  并未统一填充。受支持的破阵 17/18 不受这些更高等级扩展的影响。T5 被动数值一致，
  移经易武的重数位置已如上文所述修正。
- 来源技能 20380 现在明确给出流血的 0.33 基准以及层数系数
  0.4 / 0.5 / 0.6 / 0.8 / 1；这些与运行时的 0.132 / 0.165 /
  0.198 / 0.264 / 0.33 一致。来源 20381 与现有的 2.4 爆血系数一致。
  称这些来源数值缺失的旧文档已经过时。
- 积矩九剑第 14 阶 / 世界破阵 18 选择天赋 300601 与 0.725% 系数补偿，
  运行时已具备。来源天赋第 18 阶则要求世界等级 22 并选择 300605。
  不要将其更高的补偿导入现有的破阵 18 设置。
- 履虚扫尘、焚巢捣穴的 0.78/1.3 分支、乾坤定、愁无酒的 0.15/0.25 命中权重、
  普通扇Q的 0.8 缩放、撼玉普通/强化的数值归属以及昭阳的 0.7225 分支，
  在所检查的路线中都有相符的编写基准。共享的名称并不意味着组件可以互换：
  例如撼玉的普通拍与最后一拍引用不同的来源数值记录。
- 一些较早的威记录保留了取整或特定于路线的数值：风雷啸使用 0.3151，
  而来源 20103101 为 0.31509。惊雷震的首领命中系数与固定值经过取整。
  破石穿岩劈的 1.7562 无法直接对应导出的 20401114 基准 2.63428 及其列出的路线倍率。
  这些是精度/路线核对的候选项，而不是经过自动验证的新增强或削弱。
  在完成路线审计之前保留现有行为。
- 鹰隼已应用的 12% 补丁缩放，与部分来源记录（例如莫如法天 20901102）中仍可见的
  未缩放数值曲线/项组合不同。不要根据这一局部对比撤销已批准的补丁；
  其完整的被动/攻击路线链需要核对。
- 保留文档中记录的、经用户确认的暗灼与叶龙骧首·叠浪基准、翊的名义时机假设，
  以及明川药典有意保留的额外天赋。导出的文本/曲线并不构成全面覆盖实测结果的授权。
- 普通真气失衡的原始技能说明仍写 8%/8%，而所提供的补丁要求已实现的
  10%/10%。这是不应把每个刷新后的文本字段等同于完整最新数值行为的另一个原因。
- 当前养成 17/18 的玩家属性/精准、累计角色天赋加成以及六个地区奇物数值
  与所检查的来源行一致。超出这些设置的来源等级/装备/阶数扩展本身
  并不构成新的可选应用养成。
